# Смак Експрес — сервіс доставки їжі

Курсова робота з дисципліни «Документування програмного забезпечення та шаблони проєктування»
(НУ «Львівська політехніка», варіант 8). Виконала: Швед Ірина, ІР-44.

## Стек
- Бекенд: Python, FastAPI, SQLAlchemy, MySQL
- Фронтенд: React + Vite (буде додано)

## Швидкий запуск бекенду
```bash
docker compose up --build
```
Swagger: http://localhost:8000/docs
